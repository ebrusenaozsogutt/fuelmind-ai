# FuelMind AI

FuelMind AI, yakıt verilerini yönetmek ve ileride yapay zekâ destekli analizler sunmak için geliştirilen bir projedir.

- `backend/`: FastAPI tabanlı sunucu uygulaması ve veri katmanı başlangıç yapısı.
- `desktop/`: İleride PySide6 ile geliştirilecek masaüstü istemcisi.
- `docs/`: Proje dokümantasyonu.
- `data/`: Yerel geliştirme ve örnek veri dosyaları.
- `trained_models/`: Eğitilmiş model çıktıları için ayrılmış alan.
- `reports/`: Oluşturulan rapor çıktıları için ayrılmış alan.
- `tests/`: Proje genelindeki testler.
